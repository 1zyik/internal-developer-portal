# Internal Developer Portal (IDP) with Backstage

A self-hosted Internal Developer Portal built on [Backstage](https://backstage.io). Software templates scaffold new repos into a GitHub org, data lives in Postgres, and the portal deploys to Kubernetes and AWS.

## Stack

Backstage · GitHub ([1zyik-platform](https://github.com/1zyik-platform)) · Postgres (Neon) · Docker · Kubernetes (kind/k3d) · Helm · Terraform · AWS
